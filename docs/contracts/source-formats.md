# Source formats (WP1, frozen 2026-11-01)

Formats that `imagine-kit` parses or hashes. Skills, subagent briefs and later commands must produce exactly these. Proposal sections are written "section 5.3". Contract: `cli-contract.md`.

## 1. Source references

A source reference is `kind:rest`. `status`, `gate` and `patch apply` resolve it to a **value** (a 64-hex sha256, or `label:sha256` for `clock`). A reference whose kind has no hash (`edit:s01`, `render:final`, `vo:L02`, `g4`) is **item-only**: it can be an input of another item but is never compared by hash; staleness flows through it by propagation (section 7).

| Reference | Value |
|---|---|
| `g0:<field>` | sha256 of the canonical JSON of `project.yaml` `g0.<field>` (`format width height fps audio_mode language duration_s platform silence`) |
| `unit:<L##\|T##>` | sha256 of `"<speaker or empty>\n<text>"` of that script unit |
| `bible:<path>` | sha256 of the canonical JSON of the value at the path in `bible.yaml` |
| `style:<anchor>` | sha256 of the trimmed section body of `## <anchor>` in `style.md` |
| `shot:<sNN>.<stage>` | sha256 of the stage block of that shot in `STORY.md` (section 5) |
| `story:sha` | sha256 of `STORY.md` |
| `asset:<id>.v<N>` | the manifest entry's `sha256` if `N` is the current version of `<id>`, otherwise the literal `superseded` |
| `clock:<key>` | `label:sha256`; labels below |

Canonical JSON: keys sorted recursively, no whitespace, `undefined` dropped.

Clock labels (the recorded value carries its label; the resolver recomputes with that label): `vo.v<N>` (key = script line id; the manifest `vo` entry with that `line` and `v = N`, current version only), `music.v<N>` (key = music asset id), `scratch` (key = line id; sha256 of `tmp/scratch-vo/<key>.wav`), `readtime` (key = unit id; canonical hash of `units.<key>` in `script/readtime.yaml`).

Current version of an asset id = the highest `v` among entries whose `status` is not `rejected`. The latest version (any status) is what a gate lists.

## 2. Script units

`script/narration.md` (audio_mode `narrated`, units `L##`) or `script/copy.md` (other modes, units `T##`). One unit per line:

```
L02 [narrator]: Tonight the sea was quiet, and no ship was coming.
- T04: Forty years. One lamp.
```

Regex: `^(?:[-*]\s+)?([LT]\d{2})(?:\s+\[([a-z0-9-]+)\])?:\s+(\S.*?)\s*$`. Other lines are ignored. Only the prefix of the current mode counts. A repeated id is an error (HARD-STORY-UNIT-ONCE).

## 3. Bible paths

Dotted path into the parsed `bible.yaml`. When a segment meets an array, the element whose `id` (or `term`, for `pronunciation`) equals the segment is taken: `characters.mara.hair`, `locations.lighthouse`, `pronunciation.Skerryvore`. Gate G2 items: for each top-level key, an array of objects with `id` gives `bible:<key>.<id>` per element; any other non-empty value gives `bible:<key>`.

## 4. Style anchors

`style.md` anchors are level-2 headings `## <anchor>` (lowercase, `[a-z][a-z0-9-]*`, an optional leading `#` in the heading text is ignored): `output medium palette proportions lighting camera typography motion texture prompt-tokens banned overrides`. The body runs to the next level-1 or level-2 heading. `## output` is generated by `new` from G0 and must equal that text (HARD-STYLE-OUTPUT-READONLY):

```
- format: portrait 1080x1920 @ 30 fps
- audio_mode: narrated
- language: en
- duration: 12-15 s
- platform: generic
- silence: no
```

## 5. STORY.md

```
---
imagine_rev: 4
---

## Scene s01 — Title
- scene: one-line caption
- duration_est: 4.5s
- voiceover: [L01, L02@1.2]

Narrative paragraph.
```

- Frontmatter required; `imagine_rev` is an integer. Other frontmatter keys are preserved.
- Shot heading is exactly `## Scene sNN — Title` (em dash U+2014). Every other level 1-3 heading is an error (HyperFrames drops them silently). `id` and `title` live only in the heading.
- Metadata bullets follow the heading immediately, one `- key: value` per line, single line, no duplicates, canonical order. Everything after the first non-bullet line until the next heading is the narrative (free text, may be empty).
- Key sets (section 5.3): storyboard `scene duration_est voiceover characters location framing composition layers assets reads` (+ heading id/title + narrative), previz `duration camera parallax motion beats transition_in sound poster motion_asserts`, fx `fx grade overlays fx_notes`, edit `src status`.
- Value types: seconds `4.5s` (`duration_est duration poster`); list `[a, b]` (`characters layers overlays`: ids `[A-Za-z0-9][A-Za-z0-9._-]*`); `location`: one id; `voiceover`: list of `L##` or `T##` with optional `@<offset seconds>` (the key places script units of either kind); `beats`: list of seconds; `assets`: list of `<id>:ref|img:<w>x<h>` or `<id>:vo|music|sfx`; `fx`: list of `id=tool:name[;range=a-b][;needs_final_asset=true|false][;fallback=x][;params=x][;unsupported=true]` (no `,` `;` `]` inside values; tools `shader vfx-chain media-treatment registry css-blend css-mask`; WebGL tools `shader` and `registry` need a `fallback`); `status`: `outline|built|animated`; every other key is free single-line text.
- Stage block of a shot: the bullets of that stage; the storyboard block also includes the title and narrative.
- Integrity: `STORY.md` must equal `.history/STORY.r<imagine_rev>.md`. Anything else is `KEY_NOT_OWNED` (HARD-STORY-WRITERS). This is tamper-evidence against accidental edits; an agent that deliberately edits both files is not stopped by the CLI (planning subagents have no Write tool, which is the hard guarantee).

## 6. project.yaml

`title`, `slug`, `created`, `contract`, `g0`, `stages`, `items`, `blocked`. `items` maps an id to a record:

```yaml
unit:L01:
  kind: unit
  status: approved            # recorded: pending | proposed | approved | rejected (never "stale")
  gate: G1
  decision: { decision: approve, quote: "<verbatim user words>", note: "...", at: "<ISO time>" }
  inputs: { "unit:L01": <hash>, "g0:audio_mode": <hash>, "g4": item }   # stale-driving
  watch:  { "bible:characters.mara": <hash> }                          # hints only
  patch:  { file: stage/previz/r1.patch.yaml, sha256: <hash>, brief_hash: <optional> }
```

Item ids: `g0`, `unit:<id>`, `bible:<path>`, `style:<anchor>`, `g4`, `g5a`, `g6`, `g7`, `asset:<id>.v<N>`, `shot:<sNN>.<stage>` (written by `patch apply`); WP2 adds `vo:<line>`, `edit:<sNN>`, `render:<name>` using the same record shape.

## 7. Derived status

`status` never writes. An item whose recorded status is `approved` or `proposed` is **stale** when (a) any `inputs` entry resolves to a different value than recorded (an unresolvable source counts as `missing`), or (b) any `inputs` key is itself the id of a stale item (propagation, transitive). `watch` mismatches are listed as hints and never change the status. Gate state: `approved` (all items approved), `reopened` (some item stale), `empty` (no items yet), else `open`.

## 8. Gates

Order and prerequisites (a gate is recorded only when all its prerequisites are satisfied): G0 · G1←G0 · G2←G1 · G3←G2 · G4←G3 · G5r←G4 · G5a←G4 · G5b←G5r · G6←G5a,G5b · G7←G6. A prerequisite is satisfied when its state is `approved`, or `empty` for the asset gates G5r, G5a and G5b (a text-only film has no raster images).

Items per gate: G0 `g0`; G1 the script units; G2 bible entities; G3 style anchors; G4 `g4`; G5r latest `ref` assets; G5a latest `vo`, `music`, `sfx` assets (or `g5a` when `g0.silence` is `intentional` and there are none); G5b latest `img` assets; G6 `g6`; G7 `g7`.

Inputs recorded at approval: `g0` all g0 fields; `unit:X` itself + `g0:audio_mode`; `bible:P` itself + `g0:language`; `style:A` itself (+ `g0:format` for `output`, `typography`); `g4` `story:sha` + `g0:format` + `g0:duration_s`; `g5a` `g0:silence`; `asset:I.vN` itself + the current version of each id in the entry's `refs`; `g6` `g4` + `story:sha` + every existing `edit:*`/`render:*` item id; `g7` `g6` + `story:sha` + the same.

Asset gates also set the manifest entry: approve → `status: approved` (vo: `listen_status: ok`), reject → `status: rejected` (vo: `listen_status: redo`).

## 9. Patch inputs

`inputs.bible` keys are bible paths, `inputs.style` anchors, `inputs.units` unit ids, `inputs.clock` clock keys (value `label:hash`), `inputs.refs` `<id>.v<N>` (asset refs). Required inputs derived from the ops: `characters` → `bible:characters.<id>`; `location` → `bible:locations.<id>`; `voiceover` → `unit:<id>`; keys `camera parallax` → `style:camera`; `motion transition_in` → `style:motion`; `fx grade overlays fx_notes` → `style:texture`; any `style.md#<anchor>` in `reasons` → `style:<anchor>`.

Recorded on each touched item: base inputs `g0:format g0:duration_s g0:audio_mode`, upstream block (`shot:<id>.storyboard` for previz, `shot:<id>.previz` for fx), plus the declared inputs split by stage: previz stale-driving kinds `unit clock style asset`, fx `style clock asset`, storyboard none (all declared go to `watch`); the rest go to `watch`.

`status` prints the values: `data.sources` (all enumerable references) and any `--ref a,b` request (clock requests are written `clock:L02=vo.v1`).

## 10. Optional files

- `stage/names.yaml` (main agent, from HyperFrames listings): `transitions`, `shaders`, `registry`, `vfx_chains`, `media_treatment` (lists of names). `cut` and `crossfade` are always valid transitions. Missing file with a name to check → `HARD_NOT_RUN`.
- `tmp/scratch-vo/durations.yaml` (WP2 `tts --scratch`): `L01: 3.2` seconds per line.
- `script/readtime.yaml`: `units: { T04: { words: 9, seconds: 3.2 } }`.
