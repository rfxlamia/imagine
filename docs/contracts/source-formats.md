# Source formats (WP1, frozen 2026-11-01)

Formats that `imagine-kit` parses or hashes. Skills, subagent briefs and later commands must produce exactly these. Proposal sections are written "section 5.3". Contract: `cli-contract.md`.

## 1. Source references

A source reference is `kind:rest`. `status`, `gate` and `patch apply` resolve it to a **value** (a 64-hex sha256, or `label:sha256` for `clock`). A reference whose kind has no hash (`edit:s01`, `render:final`, `vo:L02`, `g4`) is **item-only**: it can be an input of another item but is never compared by hash; staleness flows through it by propagation (section 7).

| Reference | Value |
|---|---|
| `g0:<field>` | sha256 of the canonical JSON of `project.yaml` `g0.<field>` (`format width height fps audio_mode language duration_s platform silence`) |
| `unit:<L##\|T##>` | sha256 of `"<speaker or empty>\n<text>"` of that script unit |
| `bible:<path>` | sha256 of the canonical JSON of the value at the path in `bible.yaml` |
| `style:<anchor>` | sha256 of the trimmed section body of `## <anchor>` in `style.md` |
| `shot:<sNN>.<stage>` | sha256 of the stage block of that shot in `STORY.md` (section 5) |
| `story:sha` | sha256 of `STORY.md` |
| `asset:<id>.v<N>` | the manifest entry's `sha256` if `N` is the current version of `<id>`, otherwise the literal `superseded` |
| `clock:<key>` | `label:sha256`; labels below |
| `file:<relpath>` | sha256 of the file's raw bytes. Only `assets/plan.yaml`, `edit/index.html`, `edit/index.motion.json` and `edit/compositions/<name>.html` resolve; any other path (absolute, containing `..`, or a symlink that leaves the project) is unresolvable |

Canonical JSON: keys sorted recursively, no whitespace, `undefined` dropped.

Clock labels (the recorded value carries its label; the resolver recomputes with that label): `vo.v<N>` (key = script line id; the manifest `vo` entry with that `line` and `v = N`, current version only), `music.v<N>` (key = music asset id), `scratch` (key = line id; sha256 of `tmp/scratch-vo/<key>.wav`), `readtime` (key = unit id; canonical hash of `units.<key>` in `script/readtime.yaml`).

Current version of an asset id = the highest `v` among entries whose `status` is not `rejected`. The latest version (any status) is what a gate lists.

## 2. Script units

`script/narration.md` (audio_mode `narrated`, units `L##`) or `script/copy.md` (other modes, units `T##`). One unit per line:

```
L02 [narrator]: Tonight the sea was quiet, and no ship was coming.
- T04: Forty years. One lamp.
```

Regex: `^(?:[-*]\s+)?([LT]\d{2})(?:\s+\[([a-z0-9-]+)\])?:\s+(\S.*?)\s*$`. Other lines are ignored. Only the prefix of the current mode counts. A repeated id is an error (HARD-STORY-UNIT-ONCE).

## 3. Bible paths

Dotted path into the parsed `bible.yaml`. When a segment meets an array, the element whose `id` (or `term`, for `pronunciation`) equals the segment is taken: `characters.mara.hair`, `locations.lighthouse`, `pronunciation.Skerryvore`. Entity ids in `bible.yaml` must match `[A-Za-z0-9][A-Za-z0-9_-]*` (no dot): a path segment cannot tell an id from a sub-property, so a dotted id is a HARD error at `gate G2` and in `validate story` (HARD-ENTITIES-EXIST). Gate G2 items: for each top-level key, an array of objects with `id` gives `bible:<key>.<id>` per element; any other non-empty value gives `bible:<key>`.

## 4. Style anchors

`style.md` anchors are level-2 headings `## <anchor>` (lowercase, `[a-z][a-z0-9-]*`, an optional leading `#` in the heading text is ignored): `output medium palette proportions lighting camera typography motion texture prompt-tokens banned overrides`. The body runs to the next level-1 or level-2 heading. `## output` is generated by `new` from G0 and must equal that text (HARD-STYLE-OUTPUT-READONLY):

```
- format: portrait 1080x1920 @ 30 fps
- audio_mode: narrated
- language: en
- duration: 12-15 s
- platform: generic
- silence: no
```

## 5. STORY.md

```
---
imagine_rev: 4
---

## Scene s01 — Title
- scene: one-line caption
- duration_est: 4.5s
- voiceover: [L01, L02@1.2]

Narrative paragraph.
```

- Frontmatter required; `imagine_rev` is an integer. Other frontmatter keys are preserved.
- Shot heading is exactly `## Scene sNN — Title` (em dash U+2014). Every other level 1-3 heading is an error (HyperFrames drops them silently). `id` and `title` live only in the heading.
- Metadata bullets follow the heading immediately, one `- key: value` per line, single line, no duplicates, canonical order. Everything after the first non-bullet line until the next heading is the narrative (free text, may be empty).
- Key sets (section 5.3): storyboard `scene duration_est voiceover characters location framing composition layers assets reads` (+ heading id/title + narrative), previz `duration camera parallax motion beats transition_in sound poster motion_asserts`, fx `fx grade overlays fx_notes`, edit `src status`.
- Value types: seconds `4.5s` (`duration_est duration poster`); list `[a, b]` (`characters layers overlays`: ids `[A-Za-z0-9][A-Za-z0-9._-]*`); `location`: one id; `voiceover`: list of `L##` or `T##` with optional `@<offset seconds>` (the key places script units of either kind); `beats`: list of seconds; `assets`: list of `<id>:ref|img:<w>x<h>` or `<id>:vo|music|sfx`; `fx`: list of `id=tool:name[;range=a-b][;needs_final_asset=true|false][;fallback=x][;params=x][;unsupported=true]` (no `,` `;` `]` inside values; tools `shader vfx-chain media-treatment registry css-blend css-mask`; WebGL tools `shader` and `registry` need a `fallback`); `status`: `outline|built|animated`; every other key is free single-line text.
- Stage block of a shot: the bullets of that stage; the storyboard block also includes the title and narrative.
- Phase 1 (WP2, 2026-11-01): the edit keys `src` and `status` are reserved and never written. Edit state is the project item `edit:<sNN>` (section 6), so `STORY.md` stays byte-identical across `stage-shot`, `promote-shot`, `export-hf` and `render`.
- Integrity: `STORY.md` must equal `.history/STORY.r<imagine_rev>.md`. Anything else is `KEY_NOT_OWNED` (HARD-STORY-WRITERS). This is tamper-evidence against accidental edits; an agent that deliberately edits both files is not stopped by the CLI (planning subagents have no Write tool, which is the hard guarantee).

## 6. project.yaml

`title`, `slug`, `created`, `contract`, `g0`, `stages`, `items`, `blocked`. `items` maps an id to a record:

```yaml
unit:L01:
  kind: unit
  status: approved            # recorded: pending | proposed | approved | rejected (never "stale")
  gate: G1
  decision: { decision: approve, quote: "<verbatim user words>", note: "...", at: "<ISO time>" }
  inputs: { "unit:L01": <hash>, "g0:audio_mode": <hash>, "g4": item }   # stale-driving
  watch:  { "bible:characters.mara": <hash> }                          # hints only
  patch:  { file: stage/previz/r1.patch.yaml, sha256: <hash>, brief_hash: <optional> }
```

Item ids: `g0`, `unit:<id>`, `bible:<path>`, `style:<anchor>`, `g4`, `g5a`, `g6`, `g7`, `asset:<id>.v<N>`, `shot:<sNN>.<stage>` (written by `patch apply`); WP2 adds `edit:<sNN>` (written by `promote-shot`) and `render:<name>` (written by `render`: `render:draft` for the draft, `render:<slug>.v<N>` for a final) using the same record shape (`kind` `edit` or `render`, `status` `proposed`). `vo:<line>` is not used in Phase 1: a VO take is a manifest entry (kind `vo`, id = the line id such as `L02`) approved through G5a.

- Optional top-level `pending`: `{ rev: <N+1>, prev: { <id>: <record or null> } }`, written atomically with new records during `patch apply`; if a crash occurs before the STORY.md commit, the next apply restores `prev` entries (PROC-ATOMIC-COMMIT).

## 7. Derived status

`status` never writes. An item whose recorded status is `approved` or `proposed` is **stale** when (a) any `inputs` entry resolves to a different value than recorded (an unresolvable source counts as `missing`), or (b) any `inputs` key is itself the id of a stale item (propagation, transitive), or (c) an `inputs` entry recorded as `item` names an item that is now `rejected` or has no record at all (reason `upstream`). A `pending` or `proposed` upstream item stales nothing by itself. `watch` mismatches are listed as hints and never change the status. Gate state: `approved` (all items approved), `reopened` (some item stale), `empty` (no items yet), else `open`.

## 8. Gates

Order and prerequisites (a gate is recorded only when all its prerequisites are satisfied): G0 · G1←G0 · G2←G1 · G3←G2 · G4←G3 · G5r←G4 · G5a←G4 · G5b←G5r · G6←G5a,G5b · G7←G6. A prerequisite is satisfied when its state is `approved`, or `empty` for the asset gates G5r, G5a and G5b (a text-only film has no raster images).

Items per gate: G0 `g0`; G1 the script units; G2 bible entities; G3 style anchors; G4 `g4`; G5r latest `ref` assets; G5a latest `vo`, `music`, `sfx` assets (or `g5a` when `g0.silence` is `intentional` and there are none); G5b latest `img` assets; G6 `g6`; G7 `g7`.

Inputs recorded at approval: `g0` all g0 fields; `unit:X` itself + `g0:audio_mode`; `bible:P` itself + `g0:language`; `style:A` itself (+ `g0:format` for `output`, `typography`); `g4` `story:sha` + `g0:format` + `g0:duration_s` (+ `file:assets/plan.yaml` when that file exists); `g5a` `g0:silence`; `asset:I.vN` itself + the current version of each id in the entry's `refs`; `g6` `g4` + `story:sha` + every existing `edit:*`/`render:*` item id; `g7` `g6` + `story:sha` + the same.

Asset gates also set the manifest entry: approve → `status: approved` (vo: `listen_status: ok`), reject → `status: rejected` (vo: `listen_status: redo`).

## 9. Patch inputs

`inputs.bible` keys are bible paths, `inputs.style` anchors, `inputs.units` unit ids, `inputs.clock` clock keys (value `label:hash`), `inputs.refs` `<id>.v<N>` (asset refs). Required inputs derived from the ops: `characters` → `bible:characters.<id>`; `location` → `bible:locations.<id>`; `voiceover` → `unit:<id>`; keys `camera parallax` → `style:camera`; `motion transition_in` → `style:motion`; `fx grade overlays fx_notes` → `style:texture`; any `style.md#<anchor>` in `reasons` → `style:<anchor>`.

Recorded on each touched item: base inputs `g0:format g0:duration_s g0:audio_mode`, upstream block (`shot:<id>.storyboard` for previz, `shot:<id>.previz` for fx), plus the declared inputs split by stage: previz stale-driving kinds `unit clock style asset`, fx `style clock asset`, storyboard none (all declared go to `watch`); the rest go to `watch`.

`status` prints the values: `data.sources` (all enumerable references) and any `--ref a,b` request (clock requests are written `clock:L02=vo.v1`).

## 10. Optional files

- `stage/names.yaml` (main agent, from HyperFrames listings): `transitions`, `shaders`, `registry`, `vfx_chains`, `media_treatment` (lists of names). `cut` and `crossfade` are always valid transitions. Missing file with a name to check → `HARD_NOT_RUN`.
- `tmp/scratch-vo/durations.yaml` (WP2 `tts --scratch`): `L01: 3.2` seconds per line.
- `script/readtime.yaml`: `units: { T04: { words: 9, seconds: 3.2 } }`.

## 11. WP2 files

- `assets/plan.yaml` (main agent, part of the G4 production plan; hashed through `file:assets/plan.yaml`): the planned raster assets that `img` generates. G4 approval freezes it: it must exist when G4 is approved, and any later edit makes G4 stale. Asset ids match `[A-Za-z0-9][A-Za-z0-9_-]*` and manifest paths stay under `assets/`.

```yaml
assets:
  - id: mara-sheet                  # [A-Za-z0-9][A-Za-z0-9_-]*
    kind: ref                       # ref | img
    prompt: "Full-body character reference sheet of Mara, front view, plain off-white background"
    framing: "full body, front view, centred"   # required: every prompt states framing (PROC-FRAMING-IN-PROMPT)
    size: 1024x1536                 # generator request, WxH
    refs: []                        # img only: ids of ref assets, each G5r-approved at its current version
    required_px: { w: 1080, h: 1920 }   # img: required (resolution budget, proposal section 7.2); ref: optional
  - id: mara-climb
    kind: img
    sheet: mara-poses               # optional: pose-sheet group id (2-4 members with identical non-empty refs and size)
    background: transparent         # optional: transparent | opaque
    prompt: "Mara climbing lighthouse stairs, profile view"
    framing: "medium shot, profile view"
    size: 600x600                   # shared member size; grid request is cols*W x rows*H; order in plan.yaml = cell order
    refs: [mara-sheet]              # identical non-empty refs across group; violations are HARD_NOT_RUN (PROC-POSE-SHEET)
    required_px: { w: 500, h: 500 }
  - id: mara-pause
    kind: img
    sheet: mara-poses               # same group, refs, and size as mara-climb (a one-member group is invalid)
    background: transparent
    prompt: "Mara paused on the lighthouse stairs, three-quarter view"
    framing: "medium shot, three-quarter view"
    size: 600x600
    refs: [mara-sheet]
    required_px: { w: 500, h: 500 }
```

Optional per-asset field: `background: transparent | opaque`. Resolution when absent:

| Asset kind / membership | When `background` absent | Behavior |
|---|---|---|
| Sheet member (`sheet: <group>`) | `legacy` | Opaque-background prompt, HyperFrames remove-background on every cell, no new manifest fields |
| Other `img` (standalone, no `sheet`) | `opaque` | Standard opaque raster asset |
| `ref` | `opaque` | Standard opaque reference asset |

Rejected at load (`HARD_NOT_RUN`):
1. Sheet member with explicit `opaque` (`PROC-POSE-SHEET`).
2. A sheet group whose members resolve to different intents, including explicit vs absent (`PROC-POSE-SHEET`).
3. `ref` with `transparent` (`HARD-ASSETS-APPROVED`).

Any other value fails schema validation (`HARD-ASSETS-APPROVED`). Editing `background` after G4 approval changes the `file:assets/plan.yaml` hash, so `img` is refused with `HARD-ASSETS-APPROVED` and G4 reopens.

- Raster files: `assets/refs/<id>.v<N>.png` and `assets/img/<id>.v<N>.png`; provenance sheets `assets/sheets/<group>.<sha12>.png`; review composites `assets/composites/<id>.v<N>.png` (derived review aid for transparent-intent cutouts, never an approved asset and never read by `export-hf`, `qc` or `status`, which read manifest entries only); VO takes `assets/vo/<line>.v<N>.wav`. Versions are never overwritten. `img` work directories live in `tmp/img/<id>.v<N>/` or `tmp/img/sheet-<group>.<rand>/` (the generated `out.png` and `meta.json` with the compiled and revised prompt). Pose-sheet assets record manifest fields `sheet`, `sheet_sha256`, and `cell` (1-indexed cell order).
- `tmp/scratch-vo/<line>.wav` and `tmp/audition/<speaker>-<voice>.wav` are measurements, never assets.
- Voice config (`bible.yaml`, `characters[].voice` or top-level `narrator.voice`):
  - `engine: pocket-tts`: `model: english|indonesian`, `source: builtin:<name>|file:<path inside the project>`, `seed_base` (integer), `temperature` (number, optional). Take `n` of a line uses seed `seed_base + n`.
  - `engine: elevenlabs`: `voice_id` (required, `^[A-Za-z0-9]{8,64}$`), `voice_name` (optional, credits only), `model_id` (optional, default `eleven_v4`), `language_code` (optional ISO 639-1; default = G0 language; not sent for `eleven_multilingual_v2`), `voice_settings: { stability, similarity_boost, style, speed, use_speaker_boost }` (optional; `eleven_v4` supports only `stability` and `similarity_boost`), `seed_base` (optional, 0..4294966295). Takes get best-effort seed `seed_base + take`. Hosted TTS takes automatically manage the `## Voices (ElevenLabs)` section of `assets/CREDITS.md` with voice, model, plan tier and licence terms.
- `edit/STORYBOARD.md` and `edit/assets/<id>.v<N>.<ext>` are written by `export-hf`. `stage/edit/<shot>/` is the scene-builder shadow project: `SHOT.md`, `hyperframes.json` (copied from `edit/`), `assets/`, `compositions/<shot>.html`, `index.motion.json` (shadow-local seconds).
- `edit/index.motion.json` is `{ "version": 1, "assertions": [...] }`. Assertions merged by `promote-shot` carry a `"shot": "<sNN>"` tag (HyperFrames ignores unknown assertion fields); assertions without a `shot` tag belong to the main agent and are preserved. Only `appearsBy.bySec` carries a film time and is shifted by the shot start; `before`, `staysInFrame` and `keepsMoving` are copied unchanged.
- `post/<slug>.v<N>.mp4` (final, immutable), `review/<slug>.draft.mp4` (draft, overwritten), `review/qc.json`.
